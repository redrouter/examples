# Authorized work only

Use these examples on systems and data you own or have explicit permission to assess, within the agreed scope. Follow [RedRouter's Terms](https://redrouter.org/terms). Model output is untrusted; validate findings and proposed changes before acting.

The triage example sends only bundled fictional findings and evidence to RedRouter. It performs no scanning and exposes no shell, filesystem path, or network tool to the model. Review and redact any real data before adapting it. Content logging and opt-in Zero Data Retention are described in the [data-handling documentation](https://docs.redrouter.org/data-handling); do not assume requests are private by default.

Keep keys in environment variables. Never include keys, customer data, or live target details in issues or commits. Report vulnerabilities privately to [support@redrouter.org](mailto:support@redrouter.org).
